# Mimo - site estático

Páginas públicas do app **Mimo** (app de foco, projeto de TCC - PUC Minas),
publicadas pelo GitHub Pages.

## Páginas

- `index.html` — página inicial, com links para as demais.
- `piloto.html` — instruções para participantes do piloto (entrar no grupo, instalar o app, resolver problemas).
- `privacidade.html` — política de privacidade.

> ⚠️ **Não renomear, mover ou apagar `privacidade.html`.** A URL
> `https://andremendes2003.github.io/mimo/privacidade.html` está cadastrada no Google Play Console.

HTML estático apenas.
